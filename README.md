# Student Score Manager

A simple Python program that stores student names and scores and checks whether each student passes or fails.

## What this project does

* Gets the student's name
* Gets the student's score
* Stores the information in a list
* Checks the student's result
* Displays whether the student passed, failed, or got an excellent score

## How to run

Run the Python file:

```bash
python student_scores.py
```

Then enter the student's name and score when asked.

Name: Sara
